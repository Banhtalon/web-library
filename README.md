## ✨ Điểm Nổi Bật (v2.1.0)

- **📦 Trọn bộ 219 Mẫu Thiết kế trên 25 Danh mục**: Bao gồm đầy đủ tất cả các ví dụ trong từng nhóm (ví dụ: `Header & Navbar` đủ 9 mẫu, `Button` 8 mẫu, `Hero Sections` 11 mẫu, `Reviews` 10 mẫu, `Full Page Component` 18 mẫu...).
- **💎 100% HTML / CSS / JS Thuần Semantic (Không Dùng Class Bootstrap)**:
  - Toàn bộ 219 mẫu sử dụng class ngữ nghĩa sạch sẽ, dễ đọc (`.hero-section`, `.hero-row`, `.col-half`, `.hero-title`, `.lead-text`, `.btn-primary`, `.icon-rocket-takeoff`...) — hoàn toàn không còn class utility của Bootstrap (`py-5`, `col-lg-6`, `display-4`, `fw-bold`, `bi-*` hay `data-bs-*`).
  - Tab `CSS` được tối ưu ngắn gọn theo đúng cấu trúc từng component (kèm `@media` responsive và SVG icon nội tuyến ở cuối file), giúp code copy ra chạy độc lập 100% với giao diện đẹp y hệt bản gốc.
- **🎨 Khung Source Code Tô Màu Cú Pháp (Syntax Highlighting)**:
  - Tự động căn lề 2 dấu cách (`js-beautify`) và tô màu cú pháp (`highlight.js` bảng màu GitHub Light / Dark) cho cả 3 tab `HTML`, `CSS`, `JS`.
  - Hỗ trợ thanh cuộn ngang/dọc mượt mà và nút `📋 Copy code` sao chép nhanh chỉ với 1 cú nhấp.
- **⚡ Điều Hướng Cây Danh Mục 1-Click**: Nhấp vào bất kỳ danh mục nào ở cột `CATEGORIES` bên trái sẽ xổ ngay danh sách các mẫu con và hiển thị trực tiếp mẫu đầu tiên.

## 📁 Cấu Trúc Thư Mục

```text
web-library/
├── index.html                  # Giao diện SPA chính của ứng dụng
├── package.json                # Cấu hình lệnh chạy kiểm thử (npm test)
├── README.md                   # Tài liệu hướng dẫn sử dụng dự án
├── PROJECT_STATE.md            # Tài liệu kiến trúc & trạng thái chuẩn dành cho AI đọc lại
├── CHANGELOG.md                # Lịch sử cập nhật các phiên bản
├── css/
│   └── app.css                 # Giao diện chuẩn CodeShikhi + bảng màu Syntax Highlighting
├── js/
│   ├── preview-base.js         # CSS cơ sở, 152 biểu tượng SVG & Vanilla JS runtime cho Live Preview
│   ├── code-formatter.js       # Bộ định dạng mã nguồn (js-beautify) & tô màu cú pháp (highlight.js)
│   └── app.js                  # Logic Hash Router, Cây danh mục 219 mẫu, Scaled LivePreview
├── data/
│   ├── categories.js           # Dữ liệu 25 danh mục song ngữ Anh - Việt
│   ├── categories.json         # Bản JSON đồng bộ của 25 danh mục
│   ├── components.js           # Dữ liệu mã nguồn HTML/CSS/JS của 219 Component & Template
│   └── components/
│       └── index.json          # Bản JSON đồng bộ của 219 Component & Template
├── inbox/
│   └── README.md               # Nơi thả file mẫu mới để AI tự động chuẩn hóa & thêm vào kho
└── tests/
    └── validate-library.mjs    # Script kiểm thử tự động tính toàn vẹn dữ liệu
```
