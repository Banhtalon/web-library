[![Live Demo](https://img.shields.io/badge/Live_Demo-GitHub_Pages-2563eb?style=for-the-badge&logo=github)](https://banhtalon.github.io/web-library/)

**Code Library** là ứng dụng web tĩnh giúp tra cứu, xem trước trực tiếp (**Live Preview**), chỉnh sửa thử nghiệm (**Live Editor**) và sao chép mã nguồn của **25 danh mục Component & Template** được xây dựng hoàn toàn bằng **HTML5, CSS3 và JavaScript thuần (Vanilla JS)** — không phụ thuộc vào Bootstrap hay bất kỳ thư viện ngoài nào.

🔗 **Truy cập trực tiếp (GitHub Pages):** **[https://banhtalon.github.io/web-library/](https://banhtalon.github.io/web-library/)**

---

## ✨ Điểm Nổi Bật

- **🚫 Không phụ thuộc thư viện ngoài (Zero External Libraries)**: Mọi mẫu thiết kế được viết bằng CSS Flexbox, CSS Grid, CSS Variables và DOM JavaScript chuẩn. Bạn có thể copy dán vào bất kỳ dự án nào mà không lo xung đột class hay phải cài đặt thêm gói phụ thuộc.
- **🔲 Giao diện Tối giản với Đường viền Phân vùng Rõ nét**: Giữ phong cách tối giản, sạch sẽ, đồng thời sử dụng hệ thống viền sắc nét (`1.5px` / `2px`) và độ tương phản bề mặt cao giúp tách biệt rõ ràng từng khu vực chức năng (hỗ trợ cả **Light Mode** và **Dark Mode**).
- **⚡ Live Playground & 4 Tab Code**:
  - **4 chế độ lấy mã**: Tab `HTML` riêng, `CSS` riêng, `JavaScript` riêng, và đặc biệt là tab **`Full HTML (Gộp 1 file chạy ngay)`** kèm nút tải trực tiếp file `.html`.
  - **Sửa code trực tiếp trên trình duyệt**: Gõ sửa HTML/CSS/JS và xem kết quả cập nhật tức thì trong khung `iframe` cô lập.
  - **Kiểm tra đa thiết bị**: Chuyển đổi nhanh khung nhìn **Desktop (`100%`)**, **Tablet (`768px`)**, **Mobile (`375px`)** và chế độ **Toàn màn hình (Fullscreen)**.
- **🔍 Tìm kiếm Tiếng Việt Không Dấu**: Hỗ trợ tìm nhanh theo cả tiếng Việt có dấu, không dấu và tiếng Anh (ví dụ: gõ `"thanh dieu huong"`, `"bang gia"`, `"dem nguoc"` hay `"navbar"`, `"pricing"`, `"countdown"` đều ra kết quả chính xác).

## ⌨️ Phím Tắt Tiện Ích

| Phím tắt | Tác dụng |
| :--- | :--- |
| `/` | Đưa con trỏ chuột ngay lập tức vào ô Tìm kiếm toàn cục |
| `Ctrl + Enter` (hoặc `Cmd + Enter`) | Chạy lại khung Live Preview khi đang chỉnh sửa code trong Live Editor |
| `Esc` | Đóng cửa sổ Toàn màn hình (Fullscreen) hoặc xóa nhanh từ khóa đang tìm |

## 🚀 Cách Chạy Dưới Máy Cá Nhân & Kiểm Thử

1. **Mở trực tiếp hoặc qua Local Server**:
   - Vì dữ liệu được nạp qua `data/categories.js` và `data/components.js`, bạn có thể **nhấp đúp mở trực tiếp file `index.html`** trên trình duyệt mà không gặp lỗi CORS, hoặc mở bằng **VS Code Live Server**.
2. **Chạy bộ kiểm thử tính toàn vẹn dữ liệu**:
   ```bash
   npm test
   ```

## 🤖 Quy Trình Mở Rộng Kho Cùng AI

Dự án được thiết kế sẵn cơ chế bộ nhớ trạng thái để mở rộng lâu dài cùng AI:
1. Khi muốn thêm mẫu mới, bạn chỉ cần bỏ file `.html`, `.css`, `.js` hoặc ảnh mẫu vào thư mục [`inbox/`](./inbox/README.md) (hoặc gửi trực tiếp vào khung chat).
2. AI sẽ đọc [`PROJECT_STATE.md`](./PROJECT_STATE.md) và [`CHANGELOG.md`](./CHANGELOG.md), tự động chuyển đổi mẫu sang **HTML/CSS/JS thuần**, cập nhật `data/components.js` + `data/components/index.json`, chạy `npm test` kiểm tra và đẩy lên GitHub Pages.
