# Báo cáo kiểm thử Giai đoạn 0

## Kiểm thử tự động đã chạy

- Kiểm tra cú pháp cho toàn bộ file JavaScript.
- Kiểm tra schema dữ liệu cơ bản và `id` duy nhất.
- Tìm kiếm `can giua` trả về `display: flex`.
- Tìm kiếm `bấm nút` trả về `querySelector + click`.
- Bộ lọc HTML, CSS và JavaScript trả về đúng hai card mỗi nhóm.
- Render đủ sáu card trên desktop và mobile.
- Mở/đóng dialog chi tiết.
- Mở nội dung bằng URL hash.
- Tương tác nút bên trong sandbox iframe.
- Sửa CSS, chạy lại và xác nhận preview thay đổi.
- Đặt lại code và xác nhận preview trở về trạng thái ban đầu.
- JavaScript DOM click thay đổi nội dung đúng như ví dụ.
