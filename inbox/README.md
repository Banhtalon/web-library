# Thư mục Inbox (Nơi nhận mẫu mới cho AI xử lý)

Khi bạn muốn thêm Component hoặc Template mới vào kho, bạn có thể:
1. Thả file `.html`, `.css`, `.js`, ảnh chụp màn hình hoặc thư mục mẫu vào `inbox/` này (hoặc gửi trực tiếp vào khung chat).
2. Nhắn cho AI biết tên hoặc danh mục bạn muốn thêm.
3. AI sẽ tự động chuẩn hóa sang **HTML / CSS / JS thuần**, đưa vào `data/components/` và đẩy (`git push`) lên GitHub Pages.
